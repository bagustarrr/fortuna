# 🚀 KURSOR — воронка на мастер-класс (одна вебка, 3 пейджа)

Единый сайт для увеличения доходимости родителей на мастер-класс. Три страницы с общей логикой:
персональная ссылка → приветствие по имени → целевое действие → **тег на сделку в amoCRM**.

| URL | Что делает | Тег на сделку после действия |
|-----|-----------|------------------------------|
| `/` | лендинг со ссылками на 3 пейджа | — |
| `/video` | приветствие → видео Нурмаша → досмотрел (≥70%) | **Посмотрел видео-презентацию Нурмаш** |
| `/diagnostic` | приветствие → игровой тест → результат | **Прошёл диагностику** |
| `/fortuna` | приветствие → колесо (всегда наушники) → финал про мастер-класс | **Покрутил колесо Фортуны** |

## 🔗 Ссылка клиенту (главное)

Менеджер/бот amoCRM отправляет ссылку на нужный пейдж, подставляя **номер сделки** макросом:

```
https://ВАШ-домен.vercel.app/fortuna?deal={{lead.id}}
https://ВАШ-домен.vercel.app/video?deal={{lead.id}}
https://ВАШ-домен.vercel.app/diagnostic?deal={{lead.id}}
```

- `?deal=` — номер сделки. По нему сайт: (1) подтягивает имя родителя, имя ребёнка и время МК из amoCRM для приветствия/текстов; (2) ставит тег после целевого действия.
- UTM тоже поддерживается: `?utm_term={{lead.id}}`.
- Клиент **ничего не вводит** — путь максимально лёгкий.
- (необязательно) можно передать данные прямо в ссылке: `&client=Айгуль&child=Тимур&mk=1 августа, 15:00` — тогда сайт возьмёт их из ссылки, не обращаясь к CRM.

## ⚙️ Переменные окружения (Vercel → Settings → Environment Variables)

| Переменная | Обязательна | Значение |
|------------|-------------|----------|
| `AMO_SUBDOMAIN` | да | поддомен без `.amocrm.ru`, напр. `kursor` |
| `AMO_TOKEN` | да | **новый** долгоживущий токен amoCRM (старый из чата перевыпустить!) |
| `AMO_FIELD_CHILD` | для имени ребёнка | имя ИЛИ id поля сделки с именем ребёнка, напр. `Имя ребёнка` |
| `AMO_FIELD_MK` | для времени МК | имя ИЛИ id поля сделки со временем мастер-класса, напр. `Мастер-класс` |
| `AMO_TAG_VIDEO` | нет | текст тега (по умолч. «Посмотрел видео-презентацию Нурмаш») |
| `AMO_TAG_FORTUNA` | нет | по умолч. «Покрутил колесо Фортуны» |
| `AMO_TAG_DIAGNOSTIC` | нет | по умолч. «Прошёл диагностику» |

> Имя родителя берётся автоматически из основного контакта сделки — доп. настройки не нужны.
> Если `AMO_FIELD_CHILD` / `AMO_FIELD_MK` не заданы или поле пустое — страница просто покажет общий текст без имени ребёнка/времени.

## 🚀 Деплой на Vercel

1. Импортируйте репозиторий `bagustarrr/fortuna`. Framework Preset: **Other**. Root: `./`. Build/Output/Install — пусто.
2. Добавьте переменные окружения (таблица выше) и нажмите **Deploy** (или Redeploy).
3. Ссылку `…vercel.app/<пейдж>?deal=…` раздавайте через amoCRM.

## 🎬 Видео (важно про Git LFS)

Файл `video/nurmashvideo.mp4` (92 МБ) отслеживается через **Git LFS** (см. `.gitattributes`).
Чтобы его запушить, нужен установленный git-lfs:

```bash
git lfs install
git lfs track "*.mp4"   # уже прописано в .gitattributes
git add .gitattributes video/nurmashvideo.mp4
git commit -m "video via LFS"
git push
```

⚠️ **Vercel не всегда отдаёт LFS-файлы** — тогда видео не проигрывается (приходит файл-указатель).
Если так — залейте видео в облако (Vercel Blob / Cloudflare R2 / Bunny / YouTube) и поменяйте
одну строку в `video/index.html`:

```js
var VIDEO_SRC = "https://ссылка-на-ваше-видео.mp4";
```

## 🔒 Безопасность
- Токен amoCRM только в переменных Vercel, в коде/на страницах его нет.
- Репозиторий публичный — никогда не коммитьте реальный токен (для этого есть `.gitignore`).
- Токен, присланный в чат, считайте скомпрометированным — перевыпустите.
