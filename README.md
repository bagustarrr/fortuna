# 🎡 Колесо Фортуны Kursor + amoCRM

Лендинг с колесом фортуны для увеличения доходимости на первую встречу.
Всем всегда выпадают **наушники**. После выигрыша клиент вводит **номер своей сделки**,
и на эту сделку в amoCRM автоматически ставится тег — так менеджер видит, кто участвовал.

## Что внутри

```
index.html      — сама страница с колесом (фронтенд)
api/tag.js       — серверная функция: ставит тег на сделку в amoCRM
package.json     — конфиг проекта
.env.example     — пример переменных окружения (без реальных секретов)
.gitignore
```

---

## ⚠️ Безопасность — прочитайте обязательно

1. **Токен amoCRM НИКОГДА не кладётся в `index.html` или в код фронтенда.** Иначе любой посетитель
   увидит его через «Просмотр кода страницы» и получит полный доступ к вашей CRM.
   Токен живёт только в **переменных окружения Vercel** (секретах) и используется на сервере.
2. **Перевыпустите токен**, который вы отправляли в переписке — считайте его скомпрометированным.
   В настройках Vercel указывайте уже **новый** токен.
3. Файл `.env` с реальным токеном не коммитьте в git (он уже в `.gitignore`).

## 🚀 Деплой на Vercel (≈5 минут, бесплатно)

### Вариант А — через сайт (проще, без терминала)
1. Создайте бесплатный аккаунт на https://vercel.com
2. Залейте эту папку в репозиторий GitHub **или** установите Vercel CLI (вариант Б).
3. В Vercel: **Add New → Project** → импортируйте репозиторий.
4. Framework Preset: **Other** (ничего собирать не нужно). Нажмите **Deploy**.
5. Откройте **Settings → Environment Variables** и добавьте:

   | Name            | Value (пример)                    |
   |-----------------|-----------------------------------|
   | `AMO_SUBDOMAIN` | `kursor` (ваш поддомен без `.amocrm.ru`) |
   | `AMO_TOKEN`     | ваш **новый** долгоживущий токен  |
   | `AMO_TAG`       | `Крутил колесо фортуны` (или свой)|

6. Нажмите **Redeploy**, чтобы переменные применились.
7. Готово — ссылку вида `https://ваш-проект.vercel.app` отправляйте родителям.

### Вариант Б — через терминал (Vercel CLI)
```bash
npm i -g vercel
cd Fortuna
vercel                      # первый деплой (ответьте на вопросы)
vercel env add AMO_SUBDOMAIN
vercel env add AMO_TOKEN
vercel env add AMO_TAG
vercel --prod               # публикация
```

## 🔗 Как это работает

1. Клиент открывает ссылку → крутит колесо → выпадают наушники.
2. В окне выигрыша он вводит **номер сделки** (менеджер присылает его клиенту).
3. Страница отправляет номер на `POST /api/tag`.
4. Функция `api/tag.js` с токеном обращается к amoCRM:
   - читает текущие теги сделки (чтобы их не затереть);
   - добавляет ваш тег (`AMO_TAG`);
5. Клиент видит «Готово! Наушники закреплены за вами».
6. Менеджер в amoCRM видит тег на сделке → знает, кого ждать на встрече.

Тег отображается в фильтрах amoCRM — можно построить воронку/сегмент «участники колеса».

## 🛠 Настройка

- **Сменить тег** — поменяйте переменную `AMO_TAG` в Vercel и сделайте Redeploy.
- **Сменить поддомен** — переменная `AMO_SUBDOMAIN`.
- **Изменить призы на колесе** — массив `SEGMENTS` в `index.html` (около строки 300).
  У наушников стоит `win: true` — это единственный выигрышный сегмент, менять его положение не нужно.
- **Один прокрут на устройство** — хранится в `localStorage` браузера (ключ `kursor_wheel_v3`).

## ✅ Проверка

1. После деплоя откройте ссылку, крутаните колесо.
2. Введите номер реальной тестовой сделки из amoCRM.
3. Убедитесь, что на этой сделке появился тег.
4. Если появляется ошибка — проверьте переменные окружения и что токен новый и активный.

## Возможные ошибки (что видит клиент → причина)

| Сообщение на странице | Причина |
|---|---|
| «Сделка не найдена» | неверный номер сделки или сделка в другом аккаунте |
| «Не удалось обратиться к CRM» | токен истёк/неверный/нет прав `crm` |
| «Сервис пока не настроен» | не заданы `AMO_SUBDOMAIN`/`AMO_TOKEN` в Vercel |
| «Нет связи с сервером» | проблема сети/деплоя функции |
